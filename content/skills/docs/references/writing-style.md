# Writing Style

Write prose a practitioner would actually write and match the repository's
existing style.

- State the point first. Remove filler and sentences that only announce or
  repeat a topic.
- Prefer plain verbs such as "is", "has", and "use". Avoid inflated terms such
  as "leverage", "utilize", "robust", "seamless", "pivotal", and "showcase".
- Do not add unsupported significance claims. Attribute factual claims to
  repository evidence or remove them.
- Use straight quotes and the repository's existing punctuation conventions.
- Avoid decorative emoji, forced three-part lists, and generic conclusions.
- Keep definitions tight and consequences honest about trade-offs.
