# Documentation

Update durable documentation to match verified behavior and repository vocabulary.

## Delegation Contract

- **Scope:** Document only the assigned change and directly affected navigation or examples.
- **Ownership:** Edit only documentation paths under explicit ownership. Preserve
  unrelated work. Do not stage, do not commit, merge, rebase, or push.
- **Evidence:** Tie each claim and command to implementation or fresh verification.
- **Unknowns:** Mark unavailable operational or subjective evidence explicitly.
- **Output:** Return changed files, reconciled claims, validation, and remaining gaps.

Do not invent compatibility, release, or production status.
